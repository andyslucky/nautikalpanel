Nautikal Panel uses game server templates for game configurations. Kubernetes resources are generated programmatically by the backend.

## Template Directories

| Directory | Purpose |
|-----------|---------|
| `game-server-templates/` | Game server configurations (Minecraft, Valheim, etc.) |

## Configuring Paths

Set the game server template directory via environment variable:

```bash
export NAUTIKAL__PATHS__GAME_SERVER_TEMPLATES=game-server-templates
```

See [Game Server Templates](/templates/game-server-templates) for a complete guide to creating and organizing templates, or [Template Repositories](/templates/template-repositories) for managing multiple template sources including GitHub integration.

## Game Server Templates

Game server templates are YAML files that define how a specific game server is configured:

- Container images and resource limits
- Environment variables (with Tera template support for dynamic values)
- Service ports and protocols
- PVC storage settings
- SFTP configuration

### Template Variables

Game server templates support Tera template rendering for dynamic values in `pod_config.env`:

| Variable | Description |
|----------|-------------|
| `server.name` | Server name |
| `server.game_type` | Game type |
| `server.max_players` | Max players |
| `server.pod_config.image` | Container image |

See [Game Server Templates](/advanced/game-server-templates) for details on Tera template variables.
