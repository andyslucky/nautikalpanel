Nautikal Panel generates Kubernetes resources programmatically in the backend. This means pods, services, PVCs, and other K8s resources are created directly via the Kubernetes API rather than from template files.

However, you can still customize game server behavior extensively through **game server templates**.

## Game Server Templates

Game server templates are YAML files that define how a specific game server is configured. They are stored in the `game-server-templates/` directory and include:

- Container images and resources
- Environment variables
- Service ports and protocols
- PVC storage settings
- SFTP configuration

## Template Variables

Game server templates support Tera template rendering for dynamic values:

```yaml
pod_config:
  env:
    - name: SERVER_NAME
      value: "{{server.name}}"
    - name: MAX_PLAYERS
      value: "{{server.max_players}}"
```

Available variables include:

| Variable | Description |
|----------|-------------|
| `server.name` | Server name |
| `server.game_type` | Game type |
| `server.max_players` | Max players |
| `server.pod_config.image` | Container image |

See [Game Server Templates](/advanced/game-server-templates) for the complete guide.

## Template Directories

| Directory | Purpose |
|-----------|---------|
| `game-server-templates/` | Game server configurations (Minecraft, Valheim, etc.) |

Configure the template directory via environment variable:

```bash
export NAUTIKAL__PATHS__GAME_SERVER_TEMPLATES=game-server-templates
```

See [Template Repositories](/templates/template-repositories) for managing multiple template sources including GitHub integration.

## Customizing Kubernetes Resources

Since K8s resources are generated programmatically, direct customization of pod specs, services, or PVCs is not supported via templates. The backend handles:

- Pod creation with game server and SFTP containers
- Service exposure with configured ports
- PVC provisioning with specified storage class and size
- Secret generation for SFTP credentials

If you need specific K8s resource customizations, they must be implemented in the Rust backend code.
